# Machine Learning Applied to the Inference of Microbial Metabolic Capacity for the Degradation of Aromatic Compounds

Machine learning framework that integrates Enzyme Commission (EC) annotations, KEGG Orthology (KO) profiles, and GC-MS metabolomics data from the [National Microbiome Data Collaborative (NMDC)](https://data.microbiomedata.org/) to predict evidence of microbial aromatic-compound degradation directly from functional genomic data.

## Overview

Predicting degradation capacity from metagenomic data alone remains challenging: metagenomics measures functional *potential*, not *performance*, and metabolomic data (GC-MS) is rarely integrated with genomic annotations to build predictive models. This project builds a harmonized, biosample-aligned multi-omics dataset from three public NMDC studies and uses it to:

1. Derive a continuous **Metabolic Evidence Score (MES)** — the target — from GC-MS profiles, by identifying curated functional markers of aromatic degradation and quantifying their share of total detected peak area.
2. Build EC-, KO-, and KEGG-pathway-level feature matrices from functional genomic annotations.
3. Train and compare four classifiers (Random Forest, SVM, XGBoost, Multilayer Perceptron) to predict aromatic-degradation evidence from functional features alone.
4. Evaluate generalization with feature-ablation studies and leave-one-study-out (LOSO) cross-validation.
5. Interpret model behavior with SHAP, permutation importance, unsupervised clustering (PCA/UMAP/K-Means), and differential KO enrichment analysis between high- and low-degradation biosample clusters.

## Data sources

Three public NMDC studies were selected for having paired EC, KO, and GC-MS coverage:

| Study ID | Study | Biosamples (total) | Retained after alignment |
|---|---|---|---|
| `sty-11-547rwq94` | Earth Microbiome Project Multi-omics (EMP500) | 1,024 | 46 |
| `sty-11-8ws97026` | Harvard Forest long-term soil warming experiment | 42 | 16 |
| `sty-11-aygzgv51` | Columbia River riverbed sediment microbiome (PNNL) | 84 | 33 |

Only biosamples with EC **∩** KO **∩** GC-MS data simultaneously available are retained, yielding a final aligned dataset of **95 biosamples × 21 columns**.

## Repository structure

```
ML-BIO-TECH/
├── data/
│   ├── parquet_output_samples/   # EC, KO and GC-MS annotations as Parquet, by category/study/biosample
│   └── metadata/                 # Raw NMDC biosample/study/data-object/workflow metadata (JSON)
├── model/                        # Python modules generated by the notebooks + ko_to_kegg_pathway.tsv mapping
└── notebooks/                    # Colab notebooks — run in the order below
```

## Pipeline (notebooks, in order)

1. `preprocessing_bsm.ipynb` — walks the raw NMDC download, extracts biosample IDs, and serializes EC/KO/GC-MS annotations to Parquet. *(Optional — the repository already ships with `data/parquet_output_samples` pre-built.)*
2. `EC_processing.ipynb`, `ko_processing.ipynb`, `kegg_pathway_processing.ipynb`, `GC-MS processing.ipynb` — write the feature/target-engineering modules to `model/`.
3. `dataset_builder.ipynb` — merges EC, KO, KEGG-pathway features and the GC-MS-derived MES target by biosample, across the three studies, into the aligned dataset.
4. `train_model.ipynb` — trains and cross-validates the four classifiers.
5. `run_ablation.ipynb` — feature-ablation study (EC only / KO only / KEGG only / combinations) and leave-one-study-out validation.
6. `interpretability_unsupervised.ipynb` — SHAP, permutation importance, PCA/UMAP/K-Means clustering, and differential KO enrichment analysis.
7. `biosample_analysis.ipynb` — geographic and ecological characterization of the retained biosamples (metadata analysis for the manuscript's figures).

All notebooks are designed to run in Google Colab: each clones this public repository at the start of the session, so no local setup or Google Drive mount is required for code or data.
